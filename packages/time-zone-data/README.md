# Time-Zone Data

`@daylight-saviour/time-zone-data` owns pinned IANA-derived inputs, deterministic
generation, and bundled offline Time-Zone Data Packs.

Australian Coverage uses tzdb 2026c archive SHA-256
`e4a178a4477f3d0ea77cc31828ff72aa38feff8d61aa13e7e99e142e9d902be4`.
Evidence comes from `antarctica`, `asia`, `australasia`, `backward`,
`zone.tab`, and `zone1970.tab`. Exact rule inputs, 18 zone configurations,
coverage assumption, and fixed generation instant are reviewable in
`source/tzdb-2026c-australian-coverage.json`.

Generator interprets IANA standard-time (`s`) and wall-time transition bases
with UTC calendar arithmetic. Lord Howe therefore retains its 30-minute wall
change semantics. Generator never asks host ICU, host zoneinfo, or current
clock for civil-time rules.

Run `npm run generate --workspace @daylight-saviour/time-zone-data` after a
reviewed source/configuration change. Tests require regenerated bytes to match
committed known-good pack exactly.

## Verified IANA candidate refresh

`scripts/refresh-australian-pack.mjs` accepts an explicitly supplied IANA
`tzdata<version>.tar.gz`, its detached `.asc` signature, a separately obtained
public key, and that key's full primary fingerprint. It computes the archive
digest from the supplied bytes, verifies the signature in an isolated `gpg`
home with key retrieval disabled, parses the supported IANA source files, and
generates the Australian candidate from the reviewed coverage configuration.
The key is never taken from the archive and a copied digest is never used as
verification evidence.

The command snapshots the archive bytes before verification, then parses and
hashes that same snapshot. It activates the candidate through the shared
contract and checks all 18 zones, reviewed civil-time values, transition
boundaries, and the Validity Horizon before writing `candidate.pack.json`,
`provenance.json`, and `semantic-diff.txt` together. Use `--private-key` and
`--key-id` together to call the existing local signing seam and emit a signed
manifest. A requested signing key is loaded before a no-change decision, and an
existing signed pack is verified with its derived public key. Every output is
staged in a temporary sibling directory and swapped only after all checks pass;
a repeated verified input reports `NO CHANGE`.
The provenance records the verified fingerprint and, when a change is
reviewed, the exact expected differences and their evidence.
Semantic differences and conformance values are measured against the committed
reviewed baseline (with any exact, evidence-backed expected changes allowed);
the CLI pins that baseline to SHA-256
`5f60ca0a183524f4f960820bd8744fc9a56ea97d66c15873849d9d584039be40` and
rejects copied or otherwise substituted snapshot files.

The generated pack version contains a full SHA-256 revision of canonical pack
content with `packVersion` excluded, so a changed candidate cannot reuse an
immutable versioned path. Gzip inflation is bounded before the parser accepts
an archive.

```sh
node packages/time-zone-data/scripts/refresh-australian-pack.mjs \
  --archive /path/to/tzdata2026c.tar.gz \
  --signature /path/to/tzdata2026c.tar.gz.asc \
  --trusted-key /path/to/paul-eggert-public-key.asc \
  --trusted-fingerprint 7E3792A9D8ACF7D633BC1588ED97E90E62AA7E34 \
  --output-directory /path/to/candidate-output
```

The parser intentionally supports the small rule language used by the
reviewed Australian zones: numeric/`only`/`max` years, `-` rule types,
numeric or weekday-relative days, standard/wall/UTC transition bases, and
`%s`/`%z` formats. A future Zone segment or another unsupported rule form
fails closed. A civil-time difference requires `--expected-diff` containing
the exact structured `semanticDiff.differences`, the verified archive version
and digest, a human explanation, and HTTPS evidence entries whose
`supports` indexes identify the changes they justify. An evidence URL or a
refreshed snapshot by itself cannot approve a difference.

## Signed artifact publisher

`scripts/sign-australian-pack.mjs` reads private key material only from an
explicit file, validates pack content, signs exact committed bytes with Node
Ed25519, and emits deterministic artifacts:

```sh
output_directory="$(mktemp -d)"
node packages/time-zone-data/scripts/sign-australian-pack.mjs \
  --private-key packages/time-zone-data/test-fixtures/TEST-ONLY-ed25519-private.pem \
  --key-id test-only-2026-a \
  --output-directory "$output_directory"
```

Committed fixture key is public test material and must never sign candidate or
production data. Real signing inputs, publisher identity, artifact location,
and promotion workflow belong outside this public repository.

`scripts/serve-test-deployment.mjs` is a loopback reference deployment. It
serves manifest with ETag/Last-Modified validators and `no-cache`, while
versioned packs use one-year immutable caching:

```sh
node packages/time-zone-data/scripts/serve-test-deployment.mjs \
  --directory "$output_directory" \
  --port 8088
```

`tests/test-deployment.test.mjs` starts harness on ephemeral loopback port and
proves 200/304 behavior plus exact immutable artifact bytes. It does not mutate
cloud or private environments.
